# FSW Layer 0 — working rules

The shared data spine underneath FSW Group. Infrastructure, not an application.
Read [`docs/architecture.md`](docs/architecture.md) before changing anything structural.

## Commands

```bash
make dev        # clean clone -> database, migrations, seed, running API
make check      # what CI runs: format, lint, typecheck, migration verify, test
make test       # test suite (needs PostgreSQL; make db-up first)
make test-perf  # benchmarks
npm run db:migrate    # apply pending migrations
npm run db:codegen    # regenerate Kysely types after a migration — always commit these
npm run metadata:apply # load config/metadata/**.yaml into the database
```

## Stack (ADR-0001, ADR-0002, ADR-0005)

TypeScript strict on Node 22 · Fastify · TypeBox · Kysely · PostgreSQL 16 baseline ·
Vitest. PostgreSQL is the only datastore. Exact-pinned dependencies (ADR-0034).

## Architecture boundaries (ADR-0003)

- `src/platform/` — runtime plumbing. **Must not import a domain module.**
- `src/kernel/` — shared primitives: identifiers, clock, context, UnitOfWork.
- `src/modules/<name>/` — domain modules. **Reachable only through `index.ts`.**
- Each module owns a PostgreSQL schema: `kernel`, `audit`, `events`, `iam`, `party`,
  `pim`, `ingest`.
- Cross-schema foreign keys are encouraged; cross-module SQL is not.

Enforced by `tests/architecture/boundaries.test.ts`.

## Rules that are not negotiable

**Identifiers.** UUIDv7, generated by us, never recycled, never derived from source
data. No external system identifier is ever a canonical primary key, and no
`p21_id`-style column exists outside the `ingest` schema.

**Canonical values are derived, not authored** (ADR-0011). A mastered field is the
materialized output of survivorship over candidate values. A human editing in the admin
UI writes a candidate attributed to the `MANUAL` source — it does not update the row.
This is what makes merges reversible; do not shortcut it.

**Events** (ADR-0008, ADR-0009). Every canonical mutation emits meaningful domain
events through the UnitOfWork, in the same transaction. Never `RowUpdated`-style events.
**Payloads carry identifiers, never PII** — the deny-list check will reject it, and that
check is what lets erasure and an immutable ledger coexist. Breaking payload changes
create a new `schema_version`; a published schema is never edited.

**Migrations** (ADR-0006). Plain SQL in `db/migrations/NNNN_name.sql`. **Never edit an
applied migration** — the checksum runner will refuse to start. Reversal is a new
forward migration. High-risk changes: expand → backfill → validate → contract.

**Metadata is configuration, not code** (ADR-0017). Attributes, product types,
vocabularies, quality rules and survivorship rules live in `config/metadata/**.yaml` and
are applied by a loader. Adding a product type must never require a code change or a
migration.

**No runtime DDL, ever** (ADR-0013). Defining an attribute inserts metadata rows. It
does not create a column, an index, or a view.

**Engineering semantics** (ADR-0016). `ASME Class 150` is not `150 PSI`. `NPS 1"` is not
25.4 mm. Both are vocabulary-backed designations with no conversion path to a quantity.
Never add a "convenience" numeric alongside one.

**Units** (ADR-0015). Every quantity stores original value, original unit, normalized
base value, and dimension. UCUM codes. A bare number where a unit matters is a
validation failure, not a guess.

**Authorization** (ADR-0019). Default deny. Every route declares a permission or startup
fails. Function-level permission is never enough: scoped reads go through the repository
scope predicate. Every route needs a negative test.

**Audit** (ADR-0021). Written by the UnitOfWork, not by triggers. Secret-classified
fields are redacted before they reach the table.

**Source systems never define the domain** (ADR-0022). A P21 customer is not an
organization. A P21 ship-to is not a plant. A Pipedrive organization is not an
organization. Connectors map into canonical _commands_; they never write canonical tables.

**Nothing is silently discarded.** Bad records go to visible quarantine with a reason.
Losing candidate values are preserved. Raw source history is never mutated to make
canonical data look clean.

## Prohibited without a new ADR and owner approval

Kubernetes · service mesh · microservices · Kafka or any broker · Redis ·
Elasticsearch/OpenSearch · event sourcing as the persistence model · a policy engine ·
a schema-registry server · a workflow platform · an ORM · runtime-generated DDL ·
binaries in PostgreSQL · AI/ML/embeddings/vector search · password storage.

## Scope tripwire (ADR-0033)

Layer 0 is not an ERP, CRM, CPQ, LMS, storefront or portal. If work starts producing
order entry, inventory, quotes, pipelines, activities, valve sizing, pricing rules or
commissions — **stop and raise it**. Layer 0 is a mastered golden copy in v1: it writes
back to no source system, and it holds no pricing.

## Testing (ADR-0029)

Real PostgreSQL, never a mock. Never contact a live third party. Never weaken a test to
make it pass. Inject the clock and the identifier generator — `Date.now()` in domain
code is a lint error. See [`docs/testing.md`](docs/testing.md) for the acceptance
criteria map.

## Commits

Small and logical. Say what changed and why. Keep hand-written diffs reviewable;
generated files and migrations may be exceptions. When a genuine design fork appears,
**stop and present the options** rather than choosing silently.

## Terminology (see `docs/data-dictionary.md`)

**Organization** a company · **Site** a physical facility it operates · **Location** an
address · **Commercial account** a source-system accounting construct · **Ship-to** a
logistical role over a location — _not_ a plant · **Product** a manufacturer model
series · **Variant** an orderable configuration · **Candidate value** what one source
asserts · **Survivor** the value survivorship selected · **Source record** what a source
system actually said, preserved verbatim.
